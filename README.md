# AthenaFusionX

AthenaFusionX is an autonomous cognitive agent substrate built in Rust. It fuses active Bayesian epistemic inference, physical OS tool execution (RoboticExecutor), tree-sitter AST surgery, and Directed Acyclic Graph (DAG) task orchestration.

## Core Subsystems
- **Cortical Loop (`crates/runtime_core/src/cortical_loop.rs`)**: State-machine dialectic (Strategize -> Critique -> Execute -> Evaluate).
- **Epistemic Engine (`crates/runtime_core/src/epistemic_engine.rs`)**: Bayesian likelihood belief updates and adversarial Red Team critiques.
- **Substrate & Vector Palace (`crates/nexus_substrate`)**: SQLite (`nexus_memory.db`) with 384-dim FastEmbed vector search.
- **DAG Orchestrator (`crates/nexus_dag_orchestrator`)**: Topological multi-agent task planning and execution.
- **Physical Safety Gates**: ActionGate sandboxing, tree-sitter AST validation, and physical `cargo check` verification.
